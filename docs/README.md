## Overview

UI-Grid is a native AngularJS grid that provides a robust, feature-rich data grid component for web applications. It offers:

- **Virtualization**: Handle large datasets efficiently
- **Sorting**: Multi-column sorting capabilities
- **Filtering**: Built-in filtering with custom filter support
- **Editing**: Inline editing with validation
- **Selection**: Row and cell selection modes
- **Grouping**: Group data by columns
- **Pinning**: Pin columns to left or right
- **Resizing**: Column resizing and auto-sizing
- **Export**: Export data to CSV, PDF, and Excel
- **Accessibility**: ARIA compliance and keyboard navigation

## Browser Support

UI-Grid supports the following browsers:

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- IE 9+ (with polyfills)
